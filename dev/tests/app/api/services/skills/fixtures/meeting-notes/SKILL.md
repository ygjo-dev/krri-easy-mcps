# 회의록 정리

회의 중에 적은 메모, 녹취 텍스트, 채팅 기록을 받아 연구실 표준 형식의 회의록으로 정리한다.

## 입력

- 회의 메모 (자유 형식 텍스트, 글머리표, 녹취 원문 모두 가능)
- 있으면: 회의 이름, 날짜, 참석자 목록

## 작성 순서

1. 회의 개요(회의 이름 · 일시 · 참석자)를 먼저 채운다. 입력에 없는 값은 비워 두고 「확인 필요」라고 적는다.
2. 논의 내용을 주제별로 묶어 핵심만 3~5줄로 요약한다. 발언자 이름은 결정과 관련된 경우만 남긴다.
3. 결정 사항을 따로 모은다. 「~하기로 함」, 「확정」, 「승인」 같은 표현을 결정으로 본다.
4. 후속 조치를 표로 만든다: 할 일 · 담당자 · 기한. 담당자나 기한이 없으면 「미정」으로 적는다.
5. 마지막에 다음 회의 일정과 미해결 쟁점을 적는다.

형식은 `references/format.md` 를 따른다. 입력 · 출력 예시는 `examples/` 에 있다.

## 지켜야 할 것

- 메모에 없는 결정이나 담당자를 지어내지 않는다.
- 숫자 · 날짜 · 고유명사는 원문 그대로 옮긴다.
- 회의록은 한국어로 쓴다.
