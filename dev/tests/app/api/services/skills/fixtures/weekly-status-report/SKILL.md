# Weekly Status Report

Convert a free-form weekly work log into the lab's one-page weekly status report.

## Steps

1. Group the log entries by project.
2. For each project write: progress this week (max 3 bullets), issues or risks, and plan for next week.
3. Put a 2-sentence overall summary at the top.
4. Keep numbers, dates and dataset names exactly as written in the log.
5. If the log mentions a blocker that needs a decision from the team lead, list it under "Decisions needed".

Follow the layout in `references/template.md`.

## Do not

- Do not invent progress that is not in the log.
- Do not include personal remarks or evaluations of colleagues.
